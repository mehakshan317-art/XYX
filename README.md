# KulhWise 🌱
### Smart Shared-Canal Irrigation Management System

**Fair Water. Every Farmer. Every Turn.**

KulhWise is a zero-hardware, intelligent water rotation system designed to make shared-canal irrigation fair, transparent, and efficient.

It uses a Hydraulic and Water-Debt Scheduling Algorithm to dynamically allocate irrigation turns based on farmers' land area, crop requirements, canal transmission losses, and previous water shortages.

The system aims to reduce water disputes, improve tail-end farmer access, and promote sustainable agricultural water management.
